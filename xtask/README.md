# xtask

xtask provides some utilities to simplify import/export and debugging.

The syntax is: `cargo xtask <solo|export|import>`

## `solo`

This starts the battlesnake cli and the `rocket-server`. The game is played using the provided snake name or using `CarloConstrictor` as a default.

## `export <filename>`

This exports a generated .dot file into a PDF and opens it in firefox.

## `import <turn>`

This reads the `game_state.json` with the last 10 turns generated by the `rocket-server`, finds the given turn with the whole board state and creates a new scenario from it for the `runa`.
